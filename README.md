## 🧩 How I Solve Problems

1. Read the problem carefully and understand it
2. Work through the examples
3. Check the constraints, which hint at what approach can work
4. Think about edge cases
5. Identify the pattern
6. Optimise the solution and check time and space complexity
7. Revisit old problems regularly

### 🔍 Pattern Cheat Sheet

| If the problem says... | I think of... |
| --- | --- |
| Pair or triplet in a sorted array | Two Pointers |
| Longest or shortest contiguous subarray / substring | Sliding Window |
| Sorted array, or "minimum value that works" | Binary Search |
| Next greater / smaller element | Monotonic Stack |
| Count, frequency, duplicates, lookup | Hashing |
| Top K, kth largest, merge K lists | Heap |
| All combinations, permutations, subsets | Backtracking |
| Shortest path in an unweighted grid or graph | BFS |
| Connected components, cycle detection | DFS / Union Find |
| Number of ways, min or max with overlapping subproblems | Dynamic Programming |
